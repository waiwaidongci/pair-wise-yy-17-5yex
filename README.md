# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 样点归并

两处样点判定为同一处后，在「样点归并」页建档：选保留样点、待并入样点和生效日期。

- 尚未生效的方案中，每个待并入样点只能出现一次；重复提交会被退回并指出占用方案。
- 生效日期到期后方案自动生效：新巡测写入保留样点（原编号留痕 `mergedFromSiteId`），旧巡测仍按原编号查询。
- 改动生效日期会按日期重排待执行方案；已生效、已撤销的记录不受影响。
- 每个方案可查看受影响巡测（原编号记录 + 重定向后的新记录）。

代码分三层：判断逻辑在 `mergeDomain.js`（服务端与页面共用），存档与接口在 `server.js`，页面在 `public/app.js`。

验证：`npm test`（判断层单元 + 接口端到端，共 26 项）。
