# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 样点归并

两处样点判定为同一处后，在「样点归并」页建方案：选保留样点、待并入样点和生效日期。

- 尚未生效的方案里，每个待并入样点只能出现一次，重复会被退回并指出占用它的方案。
- 到期后方案自动生效，新巡测写入保留样点并留原编号，旧记录仍按原编号查。
- 改动生效日期会重排待执行方案；已生效的方案和巡测记录不再改动。
- 每个方案可查看受影响的巡测。

代码分层：`merge.js` 管判断，`server.js` + `data/db.json` 管存档，`public/` 管页面。
